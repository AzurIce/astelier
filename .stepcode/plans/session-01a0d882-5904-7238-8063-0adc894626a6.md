# 底部「库」升级为 UE Content Browser 式资产浏览器

## 目标（用户原话）

> 把库做成对标虚幻引擎的 explorer 那种东西，带侧边目录树。可以调缩略图大小，支持单选多选等操作。

即：`LibraryDock` 从「一条 208px 横排卡片带」升级为带**侧边目录树 + 缩略图网格 + 缩放 + 全套选择操作**的内容浏览器。

## 关键前置事实

- `data/stores/`（全局库）当前**在你的真实 data 里是空的**（此前只跑过测试且已清理）→ 平铺改层级**零迁移成本**。
- 图私有层 `data/graphs/{gid}/store/` 与 LoadImage 的 ingest/引用链路**不在本次范围**，保持不变。
- 用户的 `data/` 只读规则继续有效：一切验证在 `/tmp/atelier-verify-data` 副本上做。

## 架构决策

### D1 后端：全局库平铺 → 层级（data/stores/{子目录}/{文件}）

- **单个根 manifest**（`data/stores/manifest.json`），key = 相对路径（如 `角色/猫.png`）。比"每目录一份 manifest"更简单：移动 = 改 key，删目录 = 删前缀 key，不需要跨目录搬运 meta。
- list = **递归走磁盘**得到全部目录与文件，manifest 只提供 w/h 覆盖（兼容外部直接放入的文件）。
- 上传带 `?dir=`（空 = 根）。

### D2 后端 API（替换现有三个平铺接口）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/stores` | 全树：`{dirs:[...], files:[{path,w,h,bytes}]}` |
| POST | `/api/stores?dir=<子目录>` | 上传到指定目录 |
| POST | `/api/stores/dirs` `{path}` | 新建文件夹 |
| PATCH | `/api/stores/{path}` `{to}` | 重命名 / 移动（文件或目录，`to` 为新相对路径） |
| DELETE | `/api/stores/{path}` | 删文件，或递归删目录 |

静态路由改通配：`GET /store/*path`（axum 0.8 wildcard；matchit 通配段自带百分号解码，与既有 `/gstore/{gid}/{name}` 同构）。

### D3 安全（safe_store_path）

- 按 `/` 分段，每段非空、不为 `.`/`..`、不含 `\:*?"<>|`；段数 ≤ 8；总长 ≤ 240。
- 末段（文件）额外走扩展名白名单（png/jpg/jpeg/webp/gif，jpeg→jpg）；中间段按目录名规则。
- 解析出的真实路径必须 `starts_with(stores_root())`（双重保险）。

### D4 面板形态：底部可调高大面板 + 最大化

- 保留现有"折叠成底部细轨"基因；展开态高度默认 300px，**顶边框可拖拽调高**（240px ↔ 72vh），另有**最大化按钮**（覆盖整个视口，画布仍在下层）。
- 备选（未选）：全屏 overlay / 替换左侧 Sidebar。理由：底部 dock 与"结果图拖入收藏"动线衔接最好，拖拽调高已足够大，最大化覆盖终极需求；替换侧栏会破坏图管理入口。

### D5 前端 UI 结构（单组件 LibraryDock.svelte 重写）

```
┌─ 头：面包屑 │ 搜索 │ 新建文件夹 │ 上传 │ 缩放滑块 │ 最大化/收起 ─┐
├─ 侧栏树 ─┬─ 网格（文件夹 tile + 图片 tile，尺寸 = 滑块值）      ─┤
│  ▾ 库    │                                                      │
│   角色   │                                                      │
│   场景   │                                                      │
├─ 状态栏：N 项 │ 选中 M │ 合计 X MB ────────────────────────────┤
```

- **目录树**：递归、展开/折叠（记住展开集）、当前目录高亮、文件夹显示该层图片计数、**拖拽移动**（把网格里的项拖到树节点 = 移动）、点击节点导航。
- **网格**：文件夹在前、图片在后，按名排序；缩略图尺寸滑块 72–240px（UE 式）；空目录空态引导。
- **选择模型**：
  - 单击 = 替换选中；`Ctrl+单击` = 切换；`Shift+单击` = 范围选（按当前展示顺序）；空白处拖拽 = **框选**（marquee，与 tile 阈值 4px 区分点击/拖拽）；`Ctrl+A` 全选、`Esc` 清空、`Delete` 删所选。
  - 选中状态存在组件本地 `Set<string>`（相对路径），不落盘。
- **重命名**：双击 tile 名或 `F2` → inline 输入，回车提交、Esc 取消、失焦提交。
- **拖出到画布**：单选或多选一起拖；`dataTransfer` 同时放自定义 payload（选中集 JSON）与第一项的 `/store/...` URL（兼容 LoadImage 的 `acceptImageDrop`，它只读 text/uri-list）。
- **拖入收藏**（保留）：Generate/Preview 结果图拖进网格 = 收藏到当前目录（现有 `collect()` 改带 dir）。
- **右键菜单**：网格空白 = 新建文件夹/上传/全选；tile = 重命名/删除/在树中定位；树节点 = 新建子目录/重命名/删除。复用现有 `Popover` + `ui-menu`（Sidebar 已有同款模式，见 `Sidebar.svelte:356 onContext`）。

### D6 明确不做

- 不做多视图切换（列表/列视图）：先只做网格，滑块已覆盖密度需求。
- 不做资产元数据编辑（标签/备注/收藏星标）：manifest 暂无此设计，后续如要再加。
- 不做跨库全局搜索：只做当前库按名过滤（个人规模够用）。
- 不动 run/asset 层、图私有 store、节点引用链路。

## 风险与对策

- **通配路由冲突**：`/store/{*path}` 与既有 `/store/{name}` 替换，注意 SPA fallback 顺序（静态路由注册在 fallback 之前，已确认 main.rs 结构）。
- **拖拽移动的判定**：拖到树节点上要 preventDefault 才能 drop；树节点用 `ondragenter/over/leave/drop` 四个事件加 `dragoverRef` 高亮。
- **点击 vs 框选**：pointerdown 记起点，pointermove 超 4px 才进入框选态；否则算点击。避免"想点一下却弹出选框"。
- **移动目录到自己的子目录**：`to` 校验 `!to.starts_with(from + "/")`，禁止。
- **大量文件性能**：个人规模（<几千）一次性全树 GET + CSS 变量控尺寸足够；真到万级再考虑虚拟滚动（现在不做）。
